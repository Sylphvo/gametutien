1. Nguyên tắc code (cho người và AI Coding Agent)

  • Pattern: Singleton cho Manager cốt lõi; Object Pooling bắt buộc cho đạn, phi kiếm, quái, VFX, số sát thương; Observer/C# Events để tách gameplay khỏi UI.
  • Hiệu năng (60 FPS):
    • Không Instantiate()/Destroy() trong vòng lặp chiến đấu.
    • Không Camera.main hoặc GameObject.Find() trong Update().
    • GC Alloc = 0 trong combat (dùng OverlapCircleNonAlloc, cache mảng, không LINQ trong Update).
  • Input: New Input System hoặc Touch Input, đa chạm (joystick trái + nút phải cùng lúc).
  • Mô-đun: chia script đúng thư mục, code hoàn chỉnh, có XML summary comments, gắn được ngay vào Prefab/Scene.
  • Dữ liệu: mọi con số cân bằng nằm trong ScriptableObject, không hard-code.

3. Dữ liệu chính

using UnityEngine;

// Không đặt tên "Plane" vì trùng với UnityEngine.Plane
public enum WorldPlane { NhanGioi, LinhGioi, TienGioi }

[CreateAssetMenu(menuName = "VKDK/Realm")]
public class RealmData : ScriptableObject
{
    public string realmName;     // "Kết Đan"
    public int realmIndex;       // 1..14
    public WorldPlane plane;
    public float playerStatMultiplier = 1f; // nhân HP và sát thương người chơi trong trận
}

[CreateAssetMenu(menuName = "VKDK/Chapter")]
public class ChapterData : ScriptableObject
{
    public int chapterIndex;                       // 1..19
    public string biCanhName;                      // "Huyết Sắc Cấm Địa"
    public WorldPlane plane;
    public RealmData[] runRealms = new RealmData[4];   // 4 bậc trong trận
    public float tribulationMultiplier = 1f;       // Nhân Giới 1, Linh Giới 1.5, Tiên Giới 2
    public float enemyStatMultiplier = 1f;
    public WaveTable waves;
    public BossData eliteBoss;                     // phút 5
    public BossData chapterBoss;                   // phút 10
    public DialogueData introDialogue;
    public DialogueData outroDialogue;
    public ScriptableObject[] unlockRewards;       // linh thú, phi kiếm, thần luân...
}

[CreateAssetMenu(menuName = "VKDK/Transformation")]
public class TransformationData : ScriptableObject
{
    public string displayName;        // "Kim Lôi"
    public float swordSpeedMultiplier = 2f;
    public float damageMultiplier = 1.4f;
    public float duration = 12f;
    public Color hudColor;
    public GameObject auraVfxPrefab;  // lấy từ pool theo tag
}

Mỗi ScriptableObject có thêm trường public string id (ví dụ "chapter_01") để lưu game. ChapterData có thêm firstClearReward, replayReward. TransformationData dùng auraPoolTag (tag trong ObjectPooler) thay cho tham chiếu prefab.

SO khác cần tạo theo số liệu trang Cân bằng: PlayerBaseStats, EnemyData, WaveTable (danh sách đoạn thời gian: số con mỗi lần, chu kỳ, tối đa cùng lúc, thành phần %, sự kiện), BossData (HP, phase theo % HP, mỗi phase có các chiêu với cooldown và thời gian cảnh báo), SwordData, UpgradeCardData, EvolutionData, TribulationConfig, EconomyConfig, HerbData, PillData, BeastData, DialogueData, AdConfig, UITheme.

VkdkDataSeeder (Editor, menu Tools → VKDK → Seed Data): tạo hoặc cập nhật toàn bộ asset SO của chương 1–4 theo trang Cân bằng, để không phải nhập tay.

Scene: Boot (khởi tạo Manager, xin đồng ý UMP, khởi tạo AdMob, đọc save) → Lobby → Combat. Manager cốt lõi dùng DontDestroyOnLoad.

4. Đặc tả script

4.1. Script từ tài liệu gốc

ScriptYêu cầu
ObjectPooler.csSingleton. Dictionary các Queue GameObject theo tag (string). SpawnFromPool(string tag, Vector3 position, Quaternion rotation), ReturnToPool(string tag, GameObject obj). Cấu hình pool (tag, prefab, số lượng khởi tạo) trong Inspector; hết thì tự mở rộng và ghi cảnh báo.
AutoReturnToPool.csGắn trên prefab VFX. Trả object về ObjectPooler trong OnParticleSystemStopped() (Stop Action = Callback). FX Tool tự gắn script này.
SaveSystem.csLưu PlayerSaveData (mục 5) dạng JSON tại Application.persistentDataPath. Tự lưu khi OnApplicationPause(true), OnApplicationQuit và hết trận. Ghi file tạm rồi đổi tên để tránh hỏng save. Kiểm tra saveVersion để migrate.
FlyingSwordController.csKiếm bay quỹ đạo tròn (Mathf.Sin/Mathf.Cos). State machine Orbiting → Attacking (tìm mục tiêu bằng Physics2D.OverlapCircleNonAlloc) → Returning. Khi trúng: DamagePopup và VFX chém từ Pool. Giới hạn 36 kiếm.
TransformationHandler.csĐọc TransformationData (Thanh Lôi, Kim Lôi, Hồng Lôi). Đổi Animator Override Controller / màu sprite, bật hào quang, nhân chỉ số. Bắn static event public static event Action<Color> OnTransformationChanged khi vào và khi hết Biến Thân (gửi màu mặc định).
TribulationSystem.csTối màn hình, Coroutine gọi sét từ Pool vào vị trí ngẫu nhiên quanh người chơi với vòng cảnh báo đỏ 0.8 giây. Hết 10 giây gọi đột phá lên runRealms[n+1]. Số tia và sát thương nhân tribulationMultiplier.
FloatingJoystick.csIPointerDownHandler, IDragHandler, IPointerUpHandler. Hiện tại điểm chạm, giới hạn HandleRange, trả Vector2 Direction chuẩn hóa.
AdMobManager.csNamespace GoogleMobileAds.Api. Khởi tạo SDK, load trước Banner/Interstitial/Rewarded. ShowBanner()/HideBanner(), ShowInterstitial(Action onAdClosed) (cooldown 180 giây), ShowRewardedAd(Action onUserEarnedReward, Action onAdFailed = null) (xử lý mất mạng/chưa load, tự LoadRewardedAd() sau khi đóng). Trước khi khởi tạo SDK phải xin đồng ý của người dùng bằng User Messaging Platform (GoogleMobileAds.Ump.Api), bắt buộc với người dùng ở EEA/Anh. Callback của quảng cáo có thể chạy ngoài main thread: đẩy về main thread trước khi đụng tới Unity API (bật MobileAds.RaiseAdEventsOnUnityMainThread = true). Ad Unit ID lưu trong SO AdConfig, mặc định là Test ID của Google.
