1.2. Font

  • Dùng TextMeshPro. Font phải có đủ chữ tiếng Việt có dấu.
  • Đề xuất: font tiêu đề kiểu thư pháp/serif có hỗ trợ tiếng Việt; font nội dung Be Vietnam Pro hoặc Noto Serif (cả hai giấy phép SIL OFL, dùng thương mại được). Kiểm tra giấy phép nếu chọn font khác.
  • Font Asset dạng Dynamic, hoặc Static có bộ ký tự Latin + Vietnamese. Kiểm tra các chữ ằ, ẫ, ự, ỹ hiển thị đúng.
  • Viền và đổ bóng chữ làm bằng Material Preset của TMP (Outline, Underlay). Không dùng component Outline/Shadow của uGUI vì nhân đôi số đỉnh.

Đổi màu theo Biến Thân

using UnityEngine;
using UnityEngine.UI;

/// <summary>Gắn vào Image cần đổi màu theo trạng thái Biến Thân (viền HUD, khung avatar).</summary>
public class ThemeTint : MonoBehaviour
{
    [SerializeField] private Image target;
    [SerializeField] private Color defaultColor = Color.white;

    private void OnEnable()  => TransformationHandler.OnTransformationChanged += Apply;
    private void OnDisable() => TransformationHandler.OnTransformationChanged -= Apply;

    private void Apply(Color hudColor) => target.color = hudColor;

    public void ResetColor() => target.color = defaultColor;
}

OnTransformationChanged là static event (đã chốt ở Kỹ thuật mục 4.1). Khi hết Biến Thân, event gửi màu mặc định nên không cần gọi ResetColor() bằng tay.

5. Quy tắc hiệu năng UI

  • Tách Canvas: Canvas_Static (khung, nút ít đổi), Canvas_Dynamic (thanh máu, đồng hồ, số), Canvas_Popup. Một phần tử thay đổi sẽ làm vẽ lại cả Canvas chứa nó.
  • Tắt Raycast Target ở mọi Image/Text chỉ để trang trí.
  • Không dùng Layout Group trên phần tử cập nhật mỗi frame.
  • Pop-up ẩn bằng CanvasGroup.alpha = 0 + tắt blocksRaycasts, hoặc tắt cả Canvas. Không Instantiate pop-up mỗi lần mở.
  • Số sát thương lấy từ pool, giới hạn 30 số cùng lúc.
  • Pop-up đặt Time.timeScale = 0 thì tween UI phải dùng thời gian unscaled.

6. Cảnh kiểm tra UI Kit

Tạo scene Scenes/UIKit_Preview chứa mọi prefab ở mục 3 với dữ liệu giả. Dùng để:

  • Kiểm tra chữ tiếng Việt, độ dài chữ dài nhất (ví dụ "Nhận x2 Linh Thạch (Xem QC)").
  • Xem trên các tỉ lệ 16:9, 20:9 và máy có tai thỏ (Device Simulator) với SafeAreaHandler.
  • Thử đổi Thanh Lôi / Kim Lôi / Hồng Lôi bằng nút debug.

7. Quy trình làm một màn hình mới

  1. Họa sĩ vẽ mockup toàn màn hình tại 1920×1080.
  2. Tách ra các mảnh còn thiếu so với mục 2. Ưu tiên dùng lại mảnh có sẵn.
  3. Xuất PNG theo quy ước tên, kéo vào Art/UI/. Công cụ tự áp thiết lập import và viền 9-slice.
  4. Dựng màn từ Prefab Variant ở mục 3, thêm vào atlas tương ứng.
  5. Kiểm tra trong UIKit_Preview và Device Simulator.
