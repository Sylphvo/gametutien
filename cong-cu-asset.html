Trang này gồm ba phần: phân tích hướng dẫn đưa file .png vào Unity 2D URP, quy trình chuẩn của dự án, và đặc tả công cụ VKDK Asset Tool (Unity Editor) để tự động hóa quy trình đó.

1. Phân tích hướng dẫn gốc

Ý chính của hướng dẫn là đúng: PNG đưa thẳng vào Unity được, không cần đổi định dạng. Muốn giữ đúng hình như ảnh gốc thì cần tiền xử lý đúng loại ảnh và thiết lập import đúng. Một số điểm cần sửa để chạy được trên URP và trên Android:

Điểm trong hướng dẫnĐánh giáÁp dụng cho dự án
Ảnh hiệu ứng nền đen + Additive thì nền đen tự biến mấtĐúng. Blend Additive cộng màu, nên pixel đen (0,0,0) không làm thay đổi gì.Giữ nguyên nền đen cho mọi flipbook bake từ Niagara. Không cần tách nền.
Không dùng Magic Wand xóa nền ảnh hiệu ứngĐúng. Magic Wand cắt cứng và làm mất phần glow mờ.Giữ nguyên.
Dùng blend Screen trong Photoshop để xóa nền đenChưa đủ. Screen chỉ là chế độ hòa trộn layer, không tạo kênh alpha khi xuất PNG.Nếu cần alpha thật (ví dụ hiệu ứng ma khí dùng blend Alpha), dùng phép Unmultiply: nút có sẵn trong công cụ ở mục 3, hoặc GIMP Colors → Color to Alpha với màu đen.
Shader Mobile/Particles/AdditiveSai cho URP. Đây là shader của Built-in pipeline, trên URP sẽ hiện màu hồng.Particle System: Universal Render Pipeline/Particles/Unlit, Blending Mode Additive. SpriteRenderer: Shader Graph SG_Sprite_Additive (mục 2.3).
Sprite-Lit-Default + đổi Blending Mode sang AdditiveSai. Sprite-Lit-Default không có tùy chọn Blending Mode.Dùng Sprite-Lit-Default cho nhân vật/quái (nhận 2D Light). Dùng shader Additive riêng cho hiệu ứng.
Particles/Simple LitKhông phù hợp. Trong 2D Renderer, 2D Light không chiếu lên shader này.Dùng Particles/Unlit.
Compression: None cho mọi ảnhKhông phù hợp mobile. Ảnh 2048×2048 không nén tốn 16 MB RAM, nén ASTC 6x6 chỉ khoảng 1.8 MB.UI/nhân vật: ASTC 4x4. Hiệu ứng: ASTC 6x6. Chỉ để không nén với pixel art nhỏ hoặc ảnh bị vỡ màu rõ sau khi nén (kiểm tra trên máy thật).
Alpha Is Transparency cho ảnh hiệu ứngKhông cần. Tùy chọn này chỉ chống viền tối ở ảnh có alpha; ảnh nền đen dùng Additive không dùng alpha.Bật cho sprite và UI có nền trong suốt. Tắt cho flipbook nền đen.
Bật Bloom trong Global VolumeĐúng nhưng thiếu bước.Cần đủ: URP Asset bật HDR, Camera bật Post Processing, Global Volume có Bloom (Threshold ~1, tắt High Quality Filtering để nhẹ trên mobile), màu Material đặt HDR Intensity 1.8–2.5 để vượt Threshold.
Tâm xoay phi kiếm đặt ở chuôiTùy cách dùng.Phi kiếm bay quỹ đạo và lao vào mục tiêu: pivot ở giữa, vẽ mũi kiếm hướng lên để code dùng transform.up = direction. Kiếm vung cận chiến: pivot ở chuôi (hậu tố _hilt).
TexturePacker để gộp atlasDùng được nhưng không bắt buộc.Dùng Sprite Atlas có sẵn của Unity. Chỉ cân nhắc TexturePacker khi cần tối ưu đóng gói sâu hơn (bản trả phí).
Remove.bg / Pixelcut / PhotoroomNhanh cho nhân vật và vật phẩm viền rõ.Kiểm tra viền sau khi tách ở nền tối và nền sáng. Đọc điều khoản sử dụng thương mại của dịch vụ.
Tách layer, lưu .psb, Skinning EditorĐúng.Cần cài cả hai package 2D PSD Importer và 2D Animation.
Thiết lập chưa được nhắc tớiThiếu.Tắt Generate Mip Maps cho sprite/UI, Wrap Mode = Clamp (chống viền lem ở mép flipbook), Pixels Per Unit thống nhất = 100, Max Size ≤ 2048.

3. Công cụ VKDK Asset Tool

3.1. Chức năng

3.2. Tự áp thiết lập import

using System.IO;
using System.Text.RegularExpressions;
using UnityEditor;
using UnityEngine;

/// <summary>Tự áp thiết lập import cho PNG trong Assets/_Project/Art theo thư mục và hậu tố tên file.</summary>
public class VkdkTexturePostprocessor : AssetPostprocessor
{
    private const string Root = "Assets/_Project/Art/";

    private void OnPreprocessTexture()
    {
        if (!assetPath.StartsWith(Root)) return;
        var importer = (TextureImporter)assetImporter;
        if (!importer.importSettingsMissing) return; // chỉ lần import đầu (chưa có file .meta)

        string file = Path.GetFileNameWithoutExtension(assetPath).ToLowerInvariant();
        bool isPixel = file.Contains("_px");
        bool isFxSprite = file.Contains("_fx");

        importer.mipmapEnabled = false;
        importer.wrapMode = TextureWrapMode.Clamp;
        importer.filterMode = isPixel ? FilterMode.Point : FilterMode.Bilinear;

        // Flipbook cho Particle System: không cần là Sprite
        if (assetPath.StartsWith(Root + "VFX_Unreal/"))
        {
            importer.textureType = TextureImporterType.Default;
            importer.alphaIsTransparency = false;
            SetAndroid(importer, TextureImporterFormat.ASTC_6x6, 2048);
            return;
        }

        importer.textureType = TextureImporterType.Sprite;
        importer.spriteImportMode = SpriteImportMode.Single;
        importer.spritePixelsPerUnit = 100;
        importer.alphaIsTransparency = !isFxSprite;

        var settings = new TextureImporterSettings();
        importer.ReadTextureSettings(settings);
        settings.spriteAlignment = file.Contains("_hilt")
            ? (int)SpriteAlignment.BottomCenter
            : (int)SpriteAlignment.Center;

        Match border = Regex.Match(file, @"_9s(\d+)");
        if (border.Success)
        {
            float b = int.Parse(border.Groups[1].Value);
            settings.spriteBorder = new Vector4(b, b, b, b); // trái, dưới, phải, trên
            settings.spriteMeshType = SpriteMeshType.FullRect;
        }
        importer.SetTextureSettings(settings);

        if (isPixel)
            SetAndroid(importer, TextureImporterFormat.RGBA32, 2048);
        else
            SetAndroid(importer, isFxSprite ? TextureImporterFormat.ASTC_6x6 : TextureImporterFormat.ASTC_4x4, 2048);
    }

    private static void SetAndroid(TextureImporter importer, TextureImporterFormat format, int maxSize)
    {
        TextureImporterPlatformSettings android = importer.GetPlatformTextureSettings("Android");
        android.overridden = true;
        android.format = format;
        android.maxTextureSize = maxSize;
        importer.SetPlatformTextureSettings(android);
    }
}

3.3. Cửa sổ FX Tool

using System.IO;
using System.Text.RegularExpressions;
using UnityEditor;
using UnityEngine;

/// <summary>Tạo Material + Prefab VFX từ flipbook, Unmultiply nền đen, kiểm tra ngân sách texture.</summary>
public class VkdkFxTool : EditorWindow
{
    private const string MaterialDir = "Assets/_Project/Materials/FX";
    private const string PrefabDir = "Assets/_Project/Prefabs/VFX";
    private const string ArtDir = "Assets/_Project/Art";

    private Material template;
    private int defaultCols = 4, defaultRows = 4;
    private float lifetime = 0.5f;

    [MenuItem("Tools/VKDK/FX Tool")]
    private static void Open() => GetWindow<VkdkFxTool>("VKDK FX Tool");

    private void OnGUI()
    {
        template = (Material)EditorGUILayout.ObjectField("Material mẫu", template, typeof(Material), false);
        defaultCols = EditorGUILayout.IntField("Số cột (nếu tên không có _CxR)", defaultCols);
        defaultRows = EditorGUILayout.IntField("Số hàng (nếu tên không có _CxR)", defaultRows);
        lifetime = EditorGUILayout.FloatField("Thời gian chạy (giây)", lifetime);
        EditorGUILayout.HelpBox("Chọn một hoặc nhiều texture trong cửa sổ Project rồi bấm nút.", MessageType.Info);

        using (new EditorGUI.DisabledScope(template == null))
        {
            if (GUILayout.Button("Tạo Material + Particle Prefab")) CreateVfxForSelection();
        }
        if (GUILayout.Button("Unmultiply nền đen → alpha (tạo file _alpha.png)")) UnmultiplySelection();
        if (GUILayout.Button("Kiểm tra ngân sách texture")) ValidateTextures();
    }

    private void CreateVfxForSelection()
    {
        Directory.CreateDirectory(MaterialDir);
        Directory.CreateDirectory(PrefabDir);

        foreach (Texture2D tex in Selection.GetFiltered<Texture2D>(SelectionMode.Assets))
        {
            string name = Path.GetFileNameWithoutExtension(AssetDatabase.GetAssetPath(tex));
            int cols = defaultCols, rows = defaultRows;
            Match grid = Regex.Match(name, @"_(\d+)x(\d+)");
            if (grid.Success) { cols = int.Parse(grid.Groups[1].Value); rows = int.Parse(grid.Groups[2].Value); }

            var mat = new Material(template);
            mat.SetTexture("_BaseMap", tex);
            AssetDatabase.CreateAsset(mat, $"{MaterialDir}/M_{name}.mat");

            var go = new GameObject("VFX_" + name);
            var ps = go.AddComponent<ParticleSystem>();
            ps.Stop(true, ParticleSystemStopBehavior.StopEmittingAndClear);

            ParticleSystem.MainModule main = ps.main;
            main.duration = lifetime;
            main.loop = false;
            main.startLifetime = lifetime;
            main.startSpeed = 0f;
            main.maxParticles = 1;
            main.stopAction = ParticleSystemStopAction.Callback; // AutoReturnToPool nhận OnParticleSystemStopped

            ParticleSystem.EmissionModule emission = ps.emission;
            emission.rateOverTime = 0f;
            emission.SetBursts(new[] { new ParticleSystem.Burst(0f, 1) });

            ParticleSystem.ShapeModule shape = ps.shape;
            shape.enabled = false;

            ParticleSystem.TextureSheetAnimationModule sheet = ps.textureSheetAnimation;
            sheet.enabled = true;
            sheet.mode = ParticleSystemAnimationMode.Grid;
            sheet.numTilesX = cols;
            sheet.numTilesY = rows;

            go.GetComponent<ParticleSystemRenderer>().sharedMaterial = mat;
            go.AddComponent<AutoReturnToPool>();

            PrefabUtility.SaveAsPrefabAsset(go, $"{PrefabDir}/VFX_{name}.prefab");
            DestroyImmediate(go);
        }
        AssetDatabase.SaveAssets();
    }

    private static void UnmultiplySelection()
    {
        foreach (Texture2D tex in Selection.GetFiltered<Texture2D>(SelectionMode.Assets))
        {
            string path = AssetDatabase.GetAssetPath(tex);
            var img = new Texture2D(2, 2, TextureFormat.RGBA32, false);
            img.LoadImage(File.ReadAllBytes(path)); // đọc file gốc, không cần bật Read/Write

            Color32[] px = img.GetPixels32();
            for (int i = 0; i < px.Length; i++)
            {
                Color32 c = px[i];
                int a = Mathf.Max(c.r, Mathf.Max(c.g, c.b)); // độ sáng lớn nhất thành alpha
                px[i] = a == 0
                    ? new Color32(0, 0, 0, 0)
                    : new Color32((byte)(c.r * 255 / a), (byte)(c.g * 255 / a), (byte)(c.b * 255 / a), (byte)a);
            }
            img.SetPixels32(px);
            img.Apply();

            string outPath = Path.Combine(Path.GetDirectoryName(path), Path.GetFileNameWithoutExtension(path) + "_alpha.png");
            File.WriteAllBytes(outPath, img.EncodeToPNG());
            DestroyImmediate(img);
            AssetDatabase.ImportAsset(outPath.Replace('\\', '/'));
        }
    }

    private static void ValidateTextures()
    {
        int warnings = 0;
        foreach (string guid in AssetDatabase.FindAssets("t:Texture2D", new[] { ArtDir }))
        {
            string path = AssetDatabase.GUIDToAssetPath(guid);
            if (AssetImporter.GetAtPath(path) is not TextureImporter importer) continue;
            TextureImporterPlatformSettings android = importer.GetPlatformTextureSettings("Android");
            string file = Path.GetFileName(path);

            if (!Regex.IsMatch(file, @"^[a-z0-9_]+\.(png|psb)$"))
                { Debug.LogWarning($"Tên file nên viết thường, không dấu, không khoảng trắng: {path}"); warnings++; }
            if (android.overridden && android.maxTextureSize > 2048)
                { Debug.LogWarning($"Max Size > 2048: {path}"); warnings++; }
            if (!android.overridden)
                { Debug.LogWarning($"Chưa override Android (chưa nén ASTC): {path}"); warnings++; }
            if (importer.mipmapEnabled && importer.textureType == TextureImporterType.Sprite)
                { Debug.LogWarning($"Sprite đang bật mip map: {path}"); warnings++; }
        }
        Debug.Log($"VKDK: kiểm tra xong, {warnings} cảnh báo.");
    }
}
  • AutoReturnToPool là script runtime của dự án (xem Kỹ thuật). Script cần trả object về ObjectPooler trong OnParticleSystemStopped().
  • Unmultiply chỉ cho kết quả đúng với ảnh được render trên nền đen thuần (như Niagara Baker). Ảnh có nền xám hoặc có bóng tối thật sẽ bị mất phần tối.
  • Code trên dùng cú pháp is not (C# 9), chạy được trên Unity 2021.2 trở lên.

3.4. Cách dùng hằng ngày

  1. Tạo một lần: M_FX_Additive_Template, M_FX_Alpha_Template, SG_Sprite_Additive, Global Volume có Bloom.
  2. Đặt tên PNG theo mục 2.2 rồi kéo vào đúng thư mục trong Art/. Thiết lập import được áp tự động.
  3. Với flipbook: chọn file → Tools → VKDK → FX Tool → chọn template → Tạo Material + Particle Prefab.
  4. Thêm tag của prefab mới vào ObjectPooler.
  5. Trước khi build: bấm Kiểm tra ngân sách texture và sửa hết cảnh báo.
