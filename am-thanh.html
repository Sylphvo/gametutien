1. Kiến trúc

  • AudioMixer MainMixer với nhóm: Master → BGM, SFX, UI. Tham số expose: MasterVolume, BGMVolume, SFXVolume.
  • AudioManager (singleton): 2 AudioSource cho nhạc nền (crossfade 1.5 s, unscaled time), pool 16 AudioSource cho SFX, 2 cho UI.
  • Gọi bằng id: AudioManager.PlaySfx("sfx_sword_hit"), AudioManager.PlayBgm("bgm_nhan_gioi"). Id ánh xạ tới SoundData (ScriptableObject) trong SoundLibrary.
  • SoundData: danh sách clip (chọn ngẫu nhiên), âm lượng, dao động pitch, nhóm mixer, maxInstances, minInterval.
  • Chống chồng tiếng: cùng một id không phát quá maxInstances cùng lúc và không gần nhau hơn minInterval. Rất quan trọng với tiếng kiếm trúng khi có 36 kiếm.
  • Khi pop-up dừng game (timeScale = 0): nhạc nền giảm còn 50% qua snapshot Paused, SFX gameplay tạm dừng.

5. Âm thanh tạm để chơi ngay

Editor script VkdkPlaceholderAudio (menu Tools → VKDK → Generate Placeholder Audio) tạo file .wav tạm cho mọi id ở mục 3–4 bằng sóng sin/vuông/nhiễu ngắn (ví dụ sfx_sword_hit: nhiễu 60 ms, sfx_level_up: 3 nốt đi lên), và tạo SoundData + SoundLibrary. Khi có âm thanh thật cùng tên file thì ghi đè, không cần sửa code.

6. Nguồn âm thanh

Chỉ dùng âm thanh có giấy phép dùng thương mại (tự làm, thuê, hoặc thư viện bản quyền rõ ràng như CC0). Lưu file ghi nguồn và giấy phép của từng file trong Assets/_Project/Audio/LICENSES.md.
