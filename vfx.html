VFX – Từ Unreal Niagara sang Unity 2D URP

Tổng quan Cốt truyện & Thế giới Gameplay Tu luyện Chiến đấu Nội dung ch.5–19 Hướng dẫn & Cài đặt VFX Âm thanh UI & Quảng cáo Bộ UI Công cụ Asset Cân bằng Kỹ thuật Phát hành

Mục tiêu: hình ảnh cỡ Unreal, chạy 60 FPS trên Android tầm trung. Unity không đọc được file Niagara (.uasset), nên hiệu ứng được render ra sprite sheet trong Unreal rồi phát lại bằng Particle System trong Unity.

Asset mua trên Unreal Marketplace/Fab thường chỉ được phép dùng trong Unreal Engine. Kiểm tra license trước khi bake và đưa sang Unity.

1. Tại Unreal Engine 5

  • Dựng hiệu ứng trong Niagara System trên nền đen tuyệt đối.
  • Dùng Niagara Baker xuất flipbook .png.
LoạiVí dụLướiĐộ phân giải
NgắnVệt chém, tia lửa trúng đòn4×4 (16 frame)1024×1024
LớnCột sét Lôi Kiếp, hào quang Hồng Lôi6×6 (36 frame)2048×2048

2. Tại Unity

BướcThiết lập
Import textureTab Android → bật Override for Android → Format ASTC 6x6 block. Công cụ VKDK Asset Tool tự áp khi file nằm trong Art/VFX_Unreal/.
MaterialShader Universal Render Pipeline/Particles/Unlit, Surface Type Transparent, Blending Mode Additive, HDR Color Intensity 1.8–2.5 để bắt sáng với URP Bloom
PrefabParticleSystem với module Texture Sheet Animation khớp lưới 4×4 hoặc 6×6
PoolingGắn AutoReturnToPool.cs để trả prefab về ObjectPooler khi hết duration
Các bước Material, Prefab và Pooling được FX Tool tạo tự động từ tên file (ví dụ fx_slash_loi_4x4.png). Không dùng shader Mobile/Particles/Additive: đó là shader của Built-in pipeline và hiện màu hồng trên URP.
